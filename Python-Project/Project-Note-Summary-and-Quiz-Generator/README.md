# Note Summary and Quiz Generator 📝🤖

🔗 **Live App:** [Note Summary and Quiz Generator](https://note-summary-quiz-app.streamlit.app/)

An AI-powered web application built with Streamlit and Google Gemini that allows users to upload study notes (images) to automatically generate concise summaries in Bangla and interactive multiple-choice quizzes based on selected difficulty levels.

## Features ✨
* **Image Upload:** Upload up to 3 images of your notes/study materials.
* **AI Note Summary:** Generates concise summaries in Bangla (max 100 words) using Google Gemini.
* **Audio Transcription:** Converts the generated note summaries into spoken audio using Google Text-to-Speech (gTTS) for easy listening.
* **Interactive Quizzes:** Generates custom 3-question quizzes in Bangla based on selected difficulty levels (**Easy**, **Medium**, **Hard**).

## Tech Stack 🛠️
* **Frontend/UI:** Streamlit
* **AI Model:** Google GenAI (Gemini)
* **Audio Processing:** gTTS (Google Text-to-Speech)
* **Image Processing:** Pillow (PIL)
